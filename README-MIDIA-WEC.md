# Mídia WEC / 24H — RushHub

- As páginas WEC agora possuem uma área automática de **Mídia da corrida**.
- **Live:** botão para a fonte oficial FIA WEC/FIAWEC+.
- **Melhores momentos:** usa vídeos oficiais publicados pela FIA WEC quando há URL conhecida.
- **24 Horas de Le Mans:** inclui os melhores momentos de 2026 em player oficial do YouTube e uma área de onboards oficiais.
- O RushHub não hospeda nem retransmite os vídeos; os players/links apontam para as fontes oficiais.
