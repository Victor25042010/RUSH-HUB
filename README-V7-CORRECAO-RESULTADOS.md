# RushHub V7 — correção das tabelas e vídeos

- As tabelas de WEC, Formula E, Stock Car, Porsche Cup e F2 agora são preenchidas com posições, pilotos/equipes e pontos.
- Quando existe resultado de uma etapa verificado nesta versão, a tabela mostra o resultado da própria corrida; caso contrário, mostra a classificação atual da categoria em vez de ficar vazia.
- O bloco de vídeo usa iframe direto do YouTube quando há vídeo autorizado identificado, com botão para abrir o vídeo diretamente.
- Não há links que simplesmente levem para a página inicial da categoria no bloco de vídeo.
