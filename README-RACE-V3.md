# RushHub — corrida pages v3

Rebuild completo das 85 páginas de corrida.

- Layout novo e independente do antigo `corrida.js`/`rush-media.js`.
- Vídeos oficiais: F1 usa cards com thumbnail + link oficial; não força iframe quando a FOM bloqueia incorporação.
- Pódios F1 2026 concluídos até 06/09/2026 verificados no calendário/resultados oficiais da Formula 1.
- Circuitos F1 usam layouts SVG reais; a coleção 2026 consultada é CC0 e cobre os traçados principais, e o repositório de circuitos SVG inclui Madring.
- Categorias não-F1 sem classificação verificada não recebem nomes inventados: a página aponta para a fonte oficial.
- A página antiga da Arábia Saudita foi preservada, mas marcada como fora do calendário oficial 2026.
