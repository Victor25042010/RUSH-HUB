# GRID HUB
Central independente para acompanhar a Fórmula 1.

## Estrutura
- index.html: página inicial
- corridas/gp.html: página-base de uma corrida
- campeonatos/: páginas-base das classificações
- CSS/: estilos
- JS/: lógica
- assets/video/: vídeo de background
- assets/images/: imagens
